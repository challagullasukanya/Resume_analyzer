# 📄 AI Resume Analyzer

An AI-powered Resume Analyzer that analyzes a resume based on a target job role and provides useful feedback for improving the resume.

## 🌐 Project

**GitHub:**  
https://github.com/challagullasukanya/Resume_analyzer

## ✨ Features

- Analyze resumes using AI
- Job role matching
- Resume quality score
- Identify key strengths
- Find weak areas and improvement points
- Suggest projects to add
- Generate an improved resume
- Provide interview questions
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenRouter AI API
- Flask-CORS
- python-dotenv
